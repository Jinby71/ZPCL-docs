# 帮助文档

本栏目收录社区撰写的操作教程，内容为完成某项操作的具体步骤与对应截图。使用文档说明功能与限制，本栏目说明完成一项任务的完整过程。

## 专题索引

| 专题 | 涵盖内容 | 入口 |
| --- | --- | --- |
| 下载与安装 | 安装包与架构选择、下载、安装、覆盖升级 | 待补充 |
| 账号与登录 | 微软账号登录、离线账号 | 待补充 |
| 游戏与版本 | 安装游戏版本、安装 Forge 与 Fabric | 待补充 |
| 模组与资源 | 安装模组、导入整合包、更换资源包 | 待补充 |
| 联机 | 局域网联机、加入服务器 | 待补充 |
| 插件 | 安装插件、编写第一个插件 | 待补充 |
| 设置与优化 | 调整内存、切换渲染器 | 待补充 |

上表列出已有的专题，不构成限制。未列入的内容可以自行新增专题，无需事先申请。「入口」列填写该专题首页的链接，专题下暂无页面时保留「待补充」。

::: warning
新增专题须同时完成三处改动：创建目录与页面、在 `.vitepress/config.mts` 的侧栏登记、在本页索引表补一行。遗漏任一处，读者无法从栏目首页进入该专题，或侧栏指向不存在的页面导致构建失败。
:::
